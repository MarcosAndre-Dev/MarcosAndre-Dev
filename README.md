## Projetos em destaque

### [Data Guardian](https://github.com/MarcosAndre-Dev/DataGuardian)

![Stack do Data Guardian](https://skillicons.dev/icons?i=py,fastapi,react,ts,vite,tailwind,docker)

API que encontra dados pessoais (CPF, CNPJ, e-mail, telefone, CEP, cartão e RG) em qualquer texto, valida os dígitos verificadores, classifica o risco e protege com três estratégias: MASK, REDACT e HASH. A auditoria registra o que foi feito sem nunca gravar o valor original.

- Python, FastAPI, React, TypeScript, Vite, Tailwind e Docker Compose
- 45 testes automatizados, 98% de cobertura
- Feito em trio com spec-driven development, `main` protegida e Pull Request revisado por outro integrante
- Limites documentados no README: sem autenticação e HASH sem sal
